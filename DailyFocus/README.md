# Daily Focus

Локальный Android-ежедневник с адаптивным домашним виджетом. Считает время Firefox + ChatGPT через системный `UsageStatsManager`, хранит задачи локально и не требует StayFree.

## Виджет

Виджет автоматически перестраивается при изменении размера на Samsung/Android:

- **узкий высокий** (примерно 1×5): время, прогресс и до 4 крупных задач;
- **компактный** (например 2×3): время, цель, статус и задачи;
- **полный**: время, цель, Firefox/ChatGPT и задачи.

Строка каждой задачи имеет высоту 52dp и целиком нажимается для переключения «выполнено / не выполнено». На маленьком размере второстепенные блоки скрываются, а не обрезаются.

## Сборка

Требуются JDK 17, Android SDK 35 и Gradle 8.10.2.

```bash
cd DailyFocus
gradle testDebugUnitTest assembleDebug
```

Перед сборкой CI также запускает `tools/static_verify.py`, `tools/widget_layout_stress.py` и визуальный smoke test.
